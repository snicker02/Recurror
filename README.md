# Recurror

Recursive mirror drawing in the browser. The name combines *recur* and *mirror*. Every stroke is stored as an editable spline. Each stroke has its own symmetry group, recursion and warp, and is drawn with lit, shaded geometry across layers.

WebGL1, no dependencies, plain ES modules.

## Run

ES modules need to be served over HTTP. Opening the page as `file://` won't work.

```
cd recurror
python3 -m http.server 8000
# open http://localhost:8000
```

## One transform type

Every copy is an anti-Möbius map, z ↦ (a·w + b)/(c·w + d) with w = z or z̄.
- **Similarities** have c = 0. These are rotations, mirrors, glides, scalings and translations, which covers every Euclidean group, including all 17 wallpaper groups.
- **Hyperbolic disk automorphisms and circle inversions** need c ≠ 0.

The vertex shader evaluates the map for each vertex, then applies the optional warp. It multiplies the two Jacobians and uses the result for three things:
- extruding the stroke width in the right direction
- keeping anti-aliasing at one device pixel wherever the copy is scaled
- rotating the normals that drive the lighting

Copies smaller than about a pixel, or far off the artboard, are culled before drawing.

**Instancing.** With `ANGLE_instanced_arrays` (a WebGL1 extension available almost everywhere), each copy's Möbius coefficients are per-instance attributes, and a stroke draws in one call per recursion level and pass. Fills need even-odd stencilling for each copy on its own, so their copies are grouped into batches whose image circles don't overlap, with one instanced call per batch and pass. Without the extension (or with `?noinst` in the URL) it falls back to one call per copy. Both paths render pixel-identical output.

## Symmetry (per stroke)

| Mode | |
|---|---|
| Mirror, Rotational, Kaleidoscope, Spiral | As before: C*n*, D*n*, and the spiral similarity orbit |
| **Wallpaper** | All 17 plane groups: p1 p2 · pm pg cm pmm pmg pgg cmm · p4 p4m p4g · p3 p3m1 p31m p6 p6m. Operations are stored in fractional lattice coordinates and conjugated into world space, with copies covering the artboard. Oblique groups have adjustable cell height and angle; rectangular groups have adjustable height |
| **Hyperbolic {p,q}** | Reflection group of the (π/p, π/q, π/2) triangle in a Poincaré disk of chosen radius, built by breadth-first search outward from the centre. Turning **Reflections** off keeps only the rotation subgroup, which gives chiral, Circle Limit III-style tilings |
| **Circle inversion** | Group generated by inversions in a ring of *k* circles, plus an optional hub circle, up to a chosen word length. **Rotate with ring** adds the ring's own rotations, Rʲ ∘ w, so the figure keeps *k*-fold symmetry |

**Crop to cell** (mirror, rotational, kaleidoscope, wallpaper and hyperbolic): each copy is cut at the symmetry boundaries, so copies never overlap. For wallpaper groups the cell is a guide-aligned asymmetric unit: of each orbit it keeps the one point, inside a lattice cell, whose images have the lowest position across the cell (then the leftmost). So p1 crops to the whole guide cell, p2 to half of it (cut through the half-cell rotation centres), pm and pmm along the mirrors, p4 to a quarter triangle between the diagonals, and so on. The stroke uses the copy of that unit it starts in (judged a little way along the stroke, so a stroke begun on a wall or centre joins the cell it heads into). For the other modes the cell is the Dirichlet domain of the point where the stroke starts, the points nearer to it than to any of its images, using hyperbolic distance in {p,q} mode. For a group of isometries those cells tile the plane or disk exactly, and their walls fall on the mirror lines; for plain rotations the cell is turned so the cuts fall on the guide rays. The cut happens per pixel in the shaders, against the 16 nearest images, so it works with recursion, warps, fills, the preview while drawing and the paint bucket. Spiral and circle inversion copies aren't isometries, so they don't offer it.

**Frieze** (strip patterns): the 7 frieze groups, for borders and braids. p1 hop (translation), p11g step (glide), p1m1 sidle (mirrors across the strip), p11m jump (mirror along it), p2 spinning hop (half turns), p2mg spinning sidle and p2mm spinning jump. Set the **Repeat** length and the **Strip angle**; the guides show the centre line, the repeat lines, the mirrors and the half-turn centres. Crop to cell, recursion, the bucket and snapping all work with it.

**Knot layer** (Layers panel): every strand in the layer, and all their symmetric copies, weave over and under each other Celtic-knot style, alternating at each crossing. Each stroke keeps one height profile for all its copies; crossings between strokes and copies are solved together (opposite heights at every crossing, alternation along every strand), and the layer's strands share one depth buffer drawn in three passes. Fills go underneath; washes, glows and draw-order strokes are drawn after, unwoven. The **Celtic band** and **Celtic cord** presets turn the active layer into a knot layer. With End shading on (the Tangle presets), each strand also gets the same graphite where it passes under another, starting at the edge of the strand on top and fading over the Shade length, so the knot reads in 3D; **Under shading** scales it (0 = off).

## Scaling, rotating and fitting a drawing

In **Edit**, the selection gets an orange box around everything it draws, copies included. Drag a **corner** to scale it about the box centre (hold **Alt** to scale from the opposite corner). Drag the **round knob** above it to rotate (hold **Shift** for 15° steps). The **Selection** panel has **Fit to artboard** (scale and centre to fill 90% of the page), **Enlarge** (×1.25), **Shrink** (×0.8) and **Rotate 90°**; with nothing selected they act on the whole drawing. Everything that shapes the copies goes with the strokes: symmetry centre and angle, wallpaper tile, frieze repeat, hyperbolic disc, inversion circles, recursion offset and angle, warp scale, and the stroke's lengths (width, dashes, jitter, ink, wet spread, pattern scale), so the drawing looks the same, only bigger, smaller or turned. Wallpaper lattices have no orientation and some warps (waves, sinusoidal, cylinder, horseshoe, power) aren't rotation-symmetric, so those can be scaled but not rotated.

**Deleting a point:** in Edit, right-click it or Alt-click it; on a touch screen, long-press it. A stroke keeps at least two points.

## Drawing grid

For regular drawing without symmetry (or with it). Tick **Grid** in the top bar (or press **#** or **'**); set the type in the Document panel: **Square**, **Dots**, **Isometric** (triangles) or **Polar** (rings and spokes), with the size, subdivisions and spokes. It is centred on the artboard, fades its minor lines when zoomed out, and is never rendered or exported. With **Snap** on, points snap to grid intersections first, then onto its lines; the grid settings are saved with the document.

## Recursion (per stroke)

- **Nest**: Mᴸ ∘ G, so the whole figure repeats inside itself.
- **Branch**: each child is (g·M)ᴸ ∘ G, so every copy spawns a smaller figure. This works on top of any mode, hyperbolic and inversion included.
- **Per-level controls**: fade, hue shift, and layering (interleaved, children on top, or children beneath).
- **Wallpaper, hyperbolic and inversion** build the recursive motif first, then let the group place it. That way every tile carries the recursion:
  - nest: g ∘ Mᴸ
  - branch: g ∘ (M ∘ k)ᴸ, where k ranges over the symmetries fixing the centre. For p6m that's the 12 operations at the lattice origin; for {p,q}, the 2p rotations and reflections about the disk centre.
  - For the finite point groups this is the same as before.
- **Copy limit**: 50,000 copies per stroke, or 4,000 without instancing. When a level would exceed it, the panel shows how many copies that level needs and what to change.

## Warp (per stroke, applied to every copy)

The warps are swirl, twirl, spherical, bubble, eyefish, sinusoidal, horseshoe, waves, cylinder, power zⁿ, ripple and pinch/bulge. Each is defined as `centre + scale·V((p − centre)/scale)` and blended with the unwarped position by **Amount**. Warps that are symmetric about the centre (swirl, bubble, spherical, eyefish and others) keep rotational symmetry. Guides and snapping are warped along with the drawing.

## Stroke, width, overlaps

- **Per-point width**: the Width tool (W) sets a multiplier on each control point. The multiplier is interpolated along the spline and combined with pen pressure and taper.
- **Overlap** controls stacking where a stroke's copies cross each other, or where it crosses itself:
  - **Later part on top** or **Earlier part on top**: depth comes from the stroke's own arc length, so every copy resolves its crossings the same way.
  - **Weave**: every crossing between the stroke and its copies is detected. A parity union-find makes each crossing one-over-one-under, then makes the over/under alternate along the strand wherever that doesn't contradict a crossing. The result is one height profile shared by all copies, and **Flip weave** inverts it.
- **Draw order** keeps the old behaviour. Glow, neon and airbrush always blend.

## Brushes

**Shading** (how the strip is lit and coloured):
- Flat, Tube, Ribbon, Glow, Neon, Airbrush, and the other existing modes.
- **Rope**: 1–8 twisted strands (Strands), using the ribbon's Twist.
- **Pencil sketch**: several jittery hatched passes (Strands, Roughness).
- **Dry brush**: bristle streaks that break up with pressure and Roughness.
- **Watercolour**: translucent wash with a darker pooled rim and paper grain. Each copy paints a pixel once (one depth per copy), so a stroke that crosses itself or folds at a tight bend doesn't build up darker patches, while copies still glaze over one another.
- **Outline (hollow)**: just the rim, its thickness set by Rim.
- **Stitch**: slanted thread stitches at a fixed spacing (Spacing, Slant).

**Brush (shape, any shading)**:
- **Nib ratio / Nib angle**: a flat calligraphy nib held at a fixed angle. The width follows ratio + (1 − ratio)·|sin(direction − nib)|, and the edges are swept along the nib, so stroke ends and turns get the slanted edge a real broad pen leaves.
- **Width jitter / Jitter scale** and **Wobble / Wobble scale**: seeded, smooth noise on the width and on the centreline. It is the same in every copy and repeatable from the stroke's id. It's periodic around closed loops and fades out at blended ends, so joins stay exact.
- **Pattern**: Solid, Dashed (Dash, Gap) or Dotted (Gap). On loops the period is fitted to a whole number of repeats; dotted lines only draw whole dots, and dots replace end caps.

Inner sides of tight bends are clamped to the radius of curvature, so wide strokes no longer fold over themselves into dark fans.

New presets: Calligraphy, Brush pen, Rope, Pencil sketch, Dry brush, Watercolour, Pearls, Dotted line, Dashed line, Neon outline, Cross stitch.

**Shading and ink (any shading mode)**, for Zentangle-style strands:
- **Ink outline**: a pen line of the chosen width along both edges and round the ends. It isn't drawn across a blended join.
- **End shading** with **Shade length** (in stroke widths) and **Shade ends** (both, start or end): graphite that darkens toward the ends of the line, as if it tucks under its neighbour. The shading reaches further along the edges than down the middle, so it curves like hand shading.
- **Edge shading** with **Edge side** (left, both or right), **Grain** (pencil texture) and **Shade colour**.
- Presets: Tangle strand, Tangle tube, Inked colour band. Draw a pattern such as Y-Braid piece by piece; each piece's ends get the tuck shading.

## Realistic media

**Paper** (Document panel): one sheet under every stroke and fill. Cold-press watercolour, hot-press, toothy sketch paper or canvas, with **Grain size** and **Paper strength**. Its relief shows on the background, dry media (pencil, dry brush, bristles, stamps) skip its valleys, harder pressure fills more of them, and washes (watercolour, airbrush) settle into them and granulate. Each brush's **Paper tooth** sets how much it catches; dry media and washes react most by default.

**Ink pooling** (Brush section): more ink where the pen slowed down (the drawing speed is recorded with each freehand stroke), on sharp turns and along the edges, plus a round blot where the pen lands and lifts. Presets: Fineliner, Fountain pen, Ink brush pen.

**Wet watercolour**: give a Watercolour stroke a **Wet spread** (drawing units) and its wash is painted wet. The layer's wet washes are rendered on their own and spread: the water carries the pigment outward to an irregular wet front shaped by noise and the paper (**Blooms**), pigment gathers at that front as it dries (**Edge darkening**) and settles into the paper's valleys (**Granulation**). Washes in the same layer bleed into each other where they meet, and they sit under the layer's other strokes, so ink lines stay crisp. The spread is measured in drawing units, so it looks the same at any zoom and in exports. Preset: Wet wash; the Watercolour preset is now wet too. Set Wet spread to 0 for the fixed watercolour look.

**Bristle brush** (shading mode): the stroke is drawn as separate hairs (**Hairs** 4–48). Each hair carries its own load of paint and runs dry at its own point (**Dryness**), the hairs part on turns (**Hair spread**), and colours blend from A to B across the brush (**Colour blend**). Presets: Oil bristle, Gouache.

**Stamp brush** (shading mode): a tip stamped along the path with **Spacing**, **Scatter**, **Rotation jitter**, **Size jitter** and **Flow**. Tips: round (soft), flat, chalk, sponge, splatter, or a picture you load (its dark or opaque parts paint; it's saved inside the document). Presets: Charcoal, Soft pastel, Spray paint, Sponge.

## Pattern fills

Five fill patterns of Recurror's own design, in both the Fill panel and the bucket: **Plaitwork** (ribbons woven over and under, shaded where they dive), **Pebbles** (packed stones lit from the top left), **Scallops** (rows of shell scales tucked under the row above), **Orb rings** (a hex grid of ringed orbs) and **Chevron folds** (a ribbon folded back and forth). Colour A is the paper, Colour B the ink and shading; Angle, Scale and Weight (line weight) apply.

## Paint bucket (K)

The bucket has its own fill style: **Flat**, **Linear** or **Radial gradient**, **Dome**, or a texture (**Noise**, **Hatch**, **Cross-hatch**, **Dots**, **Cells**, **Marble**), with Colour A/B, Angle, Scale, Weight, Lit and Opacity, the same as the Fill panel. **Use Fill panel settings** copies the Fill panel's style into the bucket. Gradients span each filled area.

Click a closed area to fill it. The drawing is rendered, flood-filled by colour (**Tolerance**), traced and stored as an ordinary vector fill: a closed polyline whose holes are joined by zero-width bridges, so even-odd filling keeps islands as holes.
- **Gap close** stops the fill leaking through breaks up to about twice that wide.
- Fills of empty areas go to the bottom of the active layer, under its lines, and spread a pixel or two under them so no hairline shows. Turn off **Under the lines** to put them on top.
- **Symmetric copies** gives the fill the current symmetry, so one click fills every matching area.
- **Crop to cell** (off by default) makes the symmetry's cell walls act as borders too: the fill keeps only the part of the area inside the cell you clicked, and its copies fill the matching parts of the other cells. Works with mirror, rotational, kaleidoscope, wallpaper and hyperbolic symmetry. With it off, the traced area is used whole. With a warp on, the fill also takes the warp, so the copies follow the warped lines.
- Click on a line itself to recolour the line with Colour A (and Colour B for gradient or texture styles); its shading and ink stay. Click an existing fill to restyle it with the current bucket style.

## Layers

Besides show/hide, lock, opacity and blend mode: **Duplicate**, **Merge down**, **Solo** (show only this layer; again to show all), **Rename**, and **Copy / Cut / Paste** (Ctrl+C / X / V). Copy takes the selected strokes, or the whole active layer when nothing is selected; Paste puts copies in place on the active layer, also across documents in the same browser.

## Fills

Fills are drawn with even-odd stencilling.
- **Colour fills**: flat, linear, radial, and dome (lit).
- **Texture fills**: noise, hatch, cross-hatch, dots, cells (Worley) and marble. Patterns live in each copy's local frame, so they follow the symmetry, and **Scale**, **Weight** and **Angle** control them.
- **Lit (dome)**: any fill can take dome lighting.

Fill edges get their own anti-aliasing band, drawn just outside the stencil.

## Layers

Layers have visibility, lock, opacity and blend mode: normal, multiply, screen, overlay, darken, lighten, add or difference. Normal layers at 100% opacity draw straight into the accumulation buffer. Every other layer renders offscreen and is composited with W3C separable blending. New strokes go on the active layer, and locked or hidden layers can't be drawn on or selected.

## Selection and groups

- **Selecting (Edit, V)**: click to select a stroke, Shift-click to add one, or drag on empty space to box-select.
- **Editing**: panel changes apply to the whole selection.
- **Groups (Ctrl+G)**: grouped strokes share one symmetry, recursion and warp setting. Clicking any member selects the whole group. Ctrl+Shift+G ungroups.

## Blending touching ends

With **Spline → Blend touching ends** on (the default, saved with the document), separate open strokes on the same layer whose ends touch render as one continuous line, without being merged. "Touching" means the ends are within 40% of the stroke width.
- **Exact meeting point:** both ends meet exactly at the midpoint of the two endpoints.
- **Smooth curve:** on Catmull-Rom strokes, each end's spline uses the neighbour's next control point as its tangent, so the curve passes through the join smoothly.
- **Shared vertex:** both strokes build the joining vertex from the same three samples, the neighbour's sample across the join included. The tangent, miter and position therefore match exactly, and there's no cap at the join. Polyline and B-spline joins keep a round cap, shaded as the tube continuing, so they don't open a gap at a corner.
- **Continuous effects:** the gradient (Along stroke, Bands) and the ribbon twist run along the whole chain. Head-to-head and tail-to-tail joins are handled.
- **No taper** at a linked end.

**Loops.** A line that closes on itself has no free end, so a start-to-end gradient would put the end colour right next to the start colour. This applies to a **Closed** stroke, and to a ring of touching strokes. Loops therefore repeat seamlessly:
- **Along stroke** is mirrored: A, then B halfway round, then back to A.
- **Bands** fit a whole number of bands around the loop.
- **Ribbon twist** rounds to a whole number of turns.

Tested result: two touching Catmull-Rom strokes render pixel-identical to one merged stroke at the join. That holds for tail-to-head joins, head-to-head joins, and ends placed 6 px apart by hand.

## Joining strokes

Separate strokes that meet show a hard seam: each one runs its own gradient from start to end, and their round caps overlap. With **Spline → Join ends** on (the default), starting or ending a new line on an open stroke's end (shown by an amber ring) continues that stroke instead:
- **Starting on an end** extends that stroke. Extending from a stroke's start prepends the new points, so its direction and gradient don't flip.
- **Ending on another stroke's end** bridges the two into one stroke.
- **Ending on the same stroke's other end** closes the loop.
- **Taps followed by a drag** become one stroke.

**Join** (Ctrl+J) merges selected open strokes that you've already drawn, chaining them by nearest endpoints into the primary stroke and keeping its style. Joining works on each stroke's original (un-copied) instance, on the active layer.

## Snapping (S)

The pen, freehand start and end points, and handle drags all snap. Points take priority over lines. The snap targets are:
- the symmetry centre and the recursion anchors
- lattice nodes, cell centres and edge midpoints
- inversion circle centres, p-gon centres and vertices in the hyperbolic disk
- guide lines: mirrors, rays, lattice lines, circles and hyperbolic edges

The Centre tool snaps to artboard landmarks: centre, thirds, edges and corners.

## Files

Files are saved as JSON with format `recurror-doc`, version 2. Recurror v1 and Strophe files still open: layers and groups get sensible defaults, and the old **Tile** mode becomes a wallpaper group (p1, or pmm when cells were mirrored).

## Shared image shelf

The **⇄ Shelf** button opens the image shelf shared by all apps on [snicker02.github.io](https://snicker02.github.io/#shelf). It stores images in this browser only (IndexedDB), and every app on the site can read the same shelf.

- **Save current** puts the current view on the shelf.
- **Send to ↗** opens another app in a new tab with the image already loaded.

The shelf code lives in [`snicker02.github.io/shared/bridge.js`](https://github.com/snicker02/snicker02.github.io/blob/main/shared/bridge.js). If it can't load (for example when you're offline), the app works as before and the button is hidden.
